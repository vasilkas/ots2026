# NALOGA 1 — Analiza zahtev brez AI

**Kaj mora razjasniti razvijalec, preden lahko implementira?**

---

> **Navodilo:** Ne popravljajte zahteve. Poiščite praznine in mesta, kjer je možnih več razumnih interpretacij. Za vsako praznino zapišite, ali bi odgovor sami privzeli, kakšno je tveganje in kdo mora odločiti.
> **Skupine:** Delajte v skupinah po 2-3 osebe.
> **Čas:** 10 minut. Računalniki ostanejo zaprti.

# SKUPINSKI ODGOVORI

## Česa iz zahteve še ne moremo varno določiti?

Kako štejemo: ena praznina = ena odločitev, ki lahko spremeni vedenje sistema ali poslovni izid.

### Različica US1

Število najdenih praznin: `______`

| Praznina / odprta odločitev | Bi sami privzeli? | Tveganje\* N/S/V | Kdo naj odloči?\*\* |
| --- | --- | --- | --- |
|  | DA / NE | N / S / V |  |
|  | DA / NE | N / S / V |  |
|  | DA / NE | N / S / V |  |

|  | DA / NE | N / S / V |  |
|  | DA / NE | N / S / V |  |

|  | DA / NE | N / S / V |  |

### Različica US2

Število najdenih praznin: `______`

| Praznina / odprta odločitev | Bi sami privzeli? | Tveganje\* N/S/V | Kdo naj odloči?\*\* |
| --- | --- | --- | --- |
|  | DA / NE | N / S / V |  |
|  | DA / NE | N / S / V |  |
|  | DA / NE | N / S / V |  |
|  | DA / NE | N / S / V |  |
|  | DA / NE | N / S / V |  |
|  | DA / NE | N / S / V |  |
|  | DA / NE | N / S / V |  |
|  | DA / NE | N / S / V |  |

\* **Tveganje:** V = napačna privzeta razlaga spremeni ceno, pravico udeleženca ali vsebino računa; S = spremeni vedenje sistema, a je popravljivo; N = kozmetično.

\*\* **Kdo naj odloči:** npr. organizator, računovodstvo, product owner, pravna služba, razvijalec, …
